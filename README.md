# Homebrew tap for CineTTY

Install [CineTTY](https://github.com/h920032/cinetty) with one command:

```sh
brew install h920032/cinetty/cinetty
```

Then run:

```sh
cinetty
```

Alternatively, add the tap first:

```sh
brew tap h920032/cinetty
brew install cinetty
```

The formula installs a checksum-verified native executable and has no runtime
dependencies. Linux x86-64 and ARM64, macOS Intel, and Apple Silicon are
supported.

The formula is refreshed automatically from the latest CineTTY release. Each
update is tested on macOS and Linux using Homebrew before it is considered
ready for users.
